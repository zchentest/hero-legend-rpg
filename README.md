# ⚔️ 勇者传说 RPG

> 一款纯前端实现的日式西幻风格回合制RPG游戏

![游戏截图](https://img.shields.io/badge/游戏类型-RPG-blue) ![技术栈](https://img.shields.io/badge/技术栈-HTML%2FCSS%2FJS-orange) ![许可证](https://img.shields.io/badge/许可证-MIT-green)

## 🎮 游戏简介

《勇者传说》是一款经典的"剑与魔法"风格回合制RPG游戏。玩家扮演勇者，在9层风格各异的地图中探索、战斗、收集装备，最终挑战创世神，完成冒险之旅。

## 🌐 在线试玩

**👉 [立即开始游戏](https://shimmering-cheesecake-12b68c.netlify.app/)**

欢迎体验，祝您游戏愉快！

## ✨ 核心特性

- 🗺️ **9层地图**：从新手村到创世神域，每层独特主题，进场CG动画
- 👹 **29种怪物**：普通/精英/稀有三种品质，多层血条机制
- 👑 **9个BOSS**：从哥布林王到创世神，每个BOSS拥有专属技能和AI
- ⚔️ **回合制战斗**：技能系统、伤害浮动、BOSS技能动画、专属受击特效
- 🎒 **装备系统**：5种品质（1.0x-5.0x倍率）、浮动属性、一键回收
- 🎵 **音乐系统**：3套随机BGM + 5首神战BOSS专属BGM + 通关/死亡BGM
- 💾 **存档系统**：自动存档、多存档位
- 🎭 **角色定制**：8种角色形象可选
- 🛣️ **移动指引**：路径高亮显示，传送门需步行到达

## 🎯 游戏玩法

### 基础操作
- **移动**：点击地图格子移动角色，路径金色高亮
- **战斗**：点击怪物进入回合制战斗
- **传送**：击败BOSS后解锁下一层传送门，需步行到达

### 战斗系统
- **攻击**：普通攻击，伤害浮动±25%
- **技能**：击败BOSS解锁，每层BOSS对应专属技能
- **BOSS技能**：BOSS拥有专属技能和AI，冷却好后随机使用
- **逃跑**：放弃战斗返回村庄
- **自动**：自动战斗模式

## 🎵 音乐系统

### BGM配置（共17首）
- **3套随机BGM**：每次进入新地图随机选一套（背景/战斗/BOSS配套）
- **5首神战BGM**：5-9层BOSS专属战斗BGM
- **固定BGM**：通关胜利、普通死亡、BOSS死亡各1首

| 场景 | BGM |
|------|-----|
| 地图背景 | 3套随机（map_bgm / map_bgm2 / map_bgm3） |
| 普通战斗 | 当前套装 battle_normal |
| 1-4层BOSS | 当前套装 battle_boss |
| 5层冰霜巨龙 | god_battle.mp3 |
| 6层龙神 | god_battle2.mp3 |

## 🔧 技术实现

- **纯前端**：HTML + CSS + JavaScript 单文件实现
- **无依赖**：无需任何外部库或框架
- **响应式**：适配不同屏幕尺寸
- **本地存储**：使用 localStorage 实现存档功能
