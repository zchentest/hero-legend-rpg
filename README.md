## 🎮 游戏简介

《勇者传说》是一款经典的"剑与魔法"风格回合制RPG游戏。玩家扮演勇者，在9层风格各异的地图中探索、战斗、收集装备，最终挑战创世神，完成冒险之旅。

**画面风格**：夕阳下的骑士守护着正在咏唱终极火焰咒的法师——这是"剑与魔法"最经典的战斗瞬间。

## ✨ 核心特性

- 🗺️ **9层地图**：从新手村到创世神域，每层独特主题
- 👹 **29种怪物**：普通/精英/稀有三种品质
- 👑 **9个BOSS**：从哥布林王到创世神
- ⚔️ **回合制战斗**：技能系统、伤害浮动、速度控制
- 🎒 **装备系统**：5种品质、浮动属性、一键回收
- 💾 **存档系统**：自动存档、多存档位
- 🎭 **角色定制**：8种角色形象可选

## 🎯 游戏玩法

### 基础操作
- **移动**：点击地图格子移动角色
- **战斗**：点击怪物进入回合制战斗
- **传送**：击败BOSS后解锁下一层传送门

### 战斗系统
- **攻击**：普通攻击，伤害浮动±25%
- **技能**：解锁后可使用强力技能
- **逃跑**：放弃战斗返回村庄
- **自动**：自动战斗模式

### 装备系统
| 品质 | 倍率 | 颜色 |
|------|------|------|
| 普通 | 1.0x | 灰色 |
| 精良 | 1.2x | 绿色 |
| 优秀 | 1.5x | 蓝色 |
| 史诗 | 2.0x | 紫色 |
| 传说 | 3.0x | 金色 |

### 怪物品质
| 品质 | 概率 | 属性加成 |

| 普通 | 70% | 1.0x |
